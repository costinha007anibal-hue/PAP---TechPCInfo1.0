TÍTULO DO PROJETO
(Tema do projeto, motivo da escolha e breve descrição indicando em que consiste)

O nome do nosso projeto é "TechPCInfo", o motivo da escolha foi o intuito de facilitar a gestão das máquinas e esse projeto consiste em criar um web site onde nele se consiste em Organizar, enumerar e analisar os PCs ou outros meios eletrônicos do departamento Escolar ou para uma empresa de informática.

OBJETIVOS DO PROJETO
(Definição por tópicos das etapas do projeto)

O projeto consiste principalmente fazer o gerenciamento mais simples através de um QrCode onde posso visualizar e adquirir informações sobre aquele dispositivo em específico podendo assim encontrar ou descobrir o que tem ou o que se passa com o equipamento, também terá uma parte de criação de relatórios sobre a gestão ou concerto dos equipamentos que pode ser implementado junto com o QrCode, aparecerá como espécie de histórico de Gestões que já foram feitas naqueles dispositivos.
Também será implementado uma função de vários utilizadores como exemplo Admin (Host do Site); Empregados (Podem Criar relatórios e gerir os dispositivos) e Clientes (Podem somente Visualizar).

METODOLOGIAS / ESTRATÉGIAS
(Indicação das etapas sequenciais na resolução do projeto)

1. Levantamento de Requisitos
    - Dificuldade em saber que PC é qual na escola/empresa (sala, estado, peças).
    - Necessidade de histórico do que já foi feito em cada máquina (manutenções, avarias).
    - Consulta rápida no local, de preferência com telemóvel e QR Code.
    - Diferentes níveis de acesso:
        · Admin - gere tudo (criar, editar, apagar/recuperar equipamentos, inventário).
        · Trabalhador/Técnico - consulta, regista manutenções, usa scan/pesquisa.
        · Utilizador/Estudante (cliente) - sobretudo vê informação, sem editar nem apagar.
    - Requisitos extra definidos ao longo do projeto: fotos do equipamento, relatórios para portefólio (PDF/DOC), tema claro/escuro, wallpapers, assistente de ajuda (Tec), IDs automáticos, IP fixo.
2. Design e Modelação
Base de dados (modelo de informação):
    - Equipamentos: ID (ex.: PC-0001), nome, sala, tipo, marca, modelo, CPU, RAM, disco, SO, IP, estado, observações, imagem(ns).
    - Manutenções: data, tipo (preventiva/corretiva), descrição, associação ao equipamento (e técnico, quando aplicável).
    - Utilizadores: conta, email/domínio (para papel), palavra-passe, nome a exibir, foto/avatar, 2FA opcional.
    - Eliminados: equipamentos removidos com possibilidade de recuperar ou apagar de vez.
Interface (protótipo das páginas):
    - Login e registo de conta
    - Dashboard (lista + estatísticas + pesquisa)
    - Ficha do equipamento (specs, QR, manutenções, download de relatório)
    - Scan / busca (câmara QR + pesquisa)
    - Admin (criar/editar/eliminar/recuperar)
    - Definições (perfil, wallpaper, tema)
3. Desenvolvimento
    - Frontend: HTML, CSS (incl. Tailwind), JavaScript - páginas, animações, painéis, assistente Tec.
    - Backend: Python com Flask - API, sessões, ficheiros, base de dados.
    - Base de dados: SQLite (inventário partilhado na rede local).
    - QR Codes: geração por equipamento; conteúdo = ligação à ficha desse PC.
    - Câmara: leitura de QR no browser.
    - Permissões: controlo do que cada papel pode ver e fazer.
    - Relatórios: exportação PDF (impressão/guardar) e DOC para portefólio físico.
    - Extras de usabilidade: temas, wallpapers (incl. TechPCInfo claro/escuro), perfil com foto, ajudas por página.
4. Testes e Validação
    - Login com contas diferentes e respetivas permissões.
    - Criar equipamento com foto e ID automático; editar sem alterar o ID; IP imutável.
    - Eliminar → zona de eliminados → recuperar ou apagar definitivamente.
    - Abrir ficha, ver QR, registar manutenção.
    - Digitalizar QR e confirmar que abre o equipamento certo.
    - Gerar relatório PDF/DOC e validar conteúdo (ficha + manutenções).
    - Testar noutro PC/telemóvel na mesma rede (e HTTPS/ngrok se for preciso para a câmara no telemóvel).
5. Documentação
    - Anteprojeto da PAP (este documento).
    - Relatório final: objetivos, metodologias, desenvolvimento, testes, conclusões.
    - Preparação da apresentação e da demonstração ao vivo do site.
    - Organização de capturas de ecrã e, se possível, etiquetas QR de exemplo.
